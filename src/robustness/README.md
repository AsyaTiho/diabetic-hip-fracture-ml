# Robustness of the risk signal

Code for the manuscript Discussion subsection "Robustness of the risk signal."
Three strands, all asking whether the reported discrimination reflects disease
trajectory rather than a shortcut:

- **Landmark design**: cut every history at a fixed offset from the diabetes
  index (`diabetes_day + delta`) instead of just before the fracture, so record
  length no longer counts down to the outcome.
- **Matched cohort**: exact block on sex and birth year plus a +/- 30 day caliper
  on enrollment visibility, so age, sex, and enrollment length carry no marginal
  signal.
- **Cheater tests**: tiny logistic regressions that see only record structure
  (length, diabetes-token position, visit count) or only the age gap
  (`last_age - diabetes_age`). The age-gap cheater is the only place age is used
  anywhere in this repository, and it exists solely to demonstrate the leak that
  motivated blanking age in the shipped model.

## Run order

Landmark arm:

1. `build_landmark_split.py --delta 180` (and `--delta 30`): reproduce the
   primary split, verify it, subtract the landmark-filtered patients.
2. `build_landmark_cohort.py --delta 180` (and `--delta 30`): cut the sequences
   at the landmark and strict-filter fractures inside the window.
3. `run_landmark.sh`: LoRA fine-tune both landmark arms.

Matched arm:

4. `build_matched_table.py`: cohort side of the matching table.
5. `join_demographics.sh`: join enrolids to sex / birth year / visibility from
   the proprietary MarketScan demographic databases.
6. `run_matching.py` (overlap variant, for the attrition report) and
   `run_matching_knn.py` (the 1:k nearest-neighbour matching that actually
   balances the covariates; sweeps k and writes one parquet per k).
7. `build_matched_cohort.py --k 5`: subset the landmark sequences to the matched
   enrolids and emit the fine-tune inputs.
8. `run_matched.sh 5`: LoRA fine-tune the matched cohort.

Cheaters and figures last:

9. `cheater_structure_age.py` and `cheater_shape_decompose.py`: write / append to
   `results/robustness/cheater_results.csv`.
10. `fig_robustness.py` (composite figure) and `fig_landmark_attrition.py`
    (attrition figure + table).

The `run_*.sh` scripts do not contain a training loop: they set the arm's data,
split, and output paths and call the unified `../behrt/finetune_behrt_lora.py`.

## Environment variables

| Variable | Default | Used for |
| --- | --- | --- |
| `HIPFX_BEHRT_DIR` | `data/behrt` | sequences, labels, splits, matching artifacts (`matching/`), per-arm fine-tune output dirs |
| `HIPFX_RESULTS_DIR` | `results` | `robustness/cheater_results.csv`, figures under `figs/` |
| `HIPFX_MARKETSCAN_DEMO_DIR` | `data/marketscan_demographics` | proprietary `DEMO_2024.db` (sex, birth year) and `visibility_years2024.db` (enrollment visibility), which you must supply |
| `PYTHON` | `python` | interpreter used by the `run_*.sh` scripts |

## Data

All inputs are licensed clinical data and all outputs (`.npz`, `.pkl`, `.parquet`,
`.csv`, figures) are regenerated by running the pipeline; nothing is shipped in
this repository.
