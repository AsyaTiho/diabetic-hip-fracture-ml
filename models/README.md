# models/

Trained model checkpoints are written here. **No weights are shipped in this
repository** — they are regenerated by running the pipeline (see the top-level
README) on the licensed datasets.

Expected artifacts after a full run:

- `behrt_best.pt` — BEHRT masked-language-model pretraining checkpoint.
- `behrt_lora_best.pt` — LoRA fine-tuned 4-class hip-fracture model.
- `nn_4class_weights.pth` — sparse neural-network baseline.
- `xgboost_4class_model.json` — XGBoost baseline.

Everything in this folder except this README is git-ignored.
